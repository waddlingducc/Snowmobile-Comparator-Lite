# SledSpec second source and editorial audit

Research/retrieval date: **2026-10-01 UTC**. This is desk research, not ride testing, a reliability assessment, an inventory check or an AdSense approval prediction. All 23 retained IDs and images remain in place. Photographic rights and exact trim appearance are outside this specification audit.

## Method and evidence quality

- Reopened the exact model-year pages/specification tables for all 23 profiles. Read relevant package tables rather than navigation, adjacent trims or search snippets. Rechecked BRP's 2026 Renegade, MXZ and Freeride PDFs and the selected Polaris configuration pages. Family starting prices remain separate from configuration quotes.
- Arctic Cat's [2026 manufacturer archive](https://www.arcticcat.com/past-model-resources/2026?hsLang=en-us) establishes all six retained names and links their manuals. Read **all four extraction chunks** of each manual, through Reference Information, not just the opening EU-code table. The five two-stroke archive links contain the same shared ZR/Riot/M 600/858 manual (p/n 653-00054, 6/25; extraction approximately 154,066 characters). Pantera's shared 7000/9000 manual is p/n 653-00049 (approximately 155,377 characters). Graphic safety-label extraction is partly garbled; readable prose and tables, not corrupted pictograms, support the editorial additions. Manuals are operating/service evidence, not configuration-level sales sheets.
- Found a **manufacturer-authored but third-party-hosted** [26-page MY2026 specification booklet](https://www.arcticinsider.com/wp-content/uploads/2025/05/2026-ARCTIC-CAT-MODEL-SPECS.pdf). It carries Arctic Cat branding and © Arctic Cat 2025. Read both web-extraction chunks and cross-checked native PDF text with `pdftotext -layout`, particularly where suspension columns were missing from web extraction. The booklet is not described as manufacturer-hosted, and its “specs subject to change” condition remains explicit.
- Reopened the five Yamaha archived model pages and their separate `/specs` tables completely. Large current navigation was excluded from interpretation only after identifying the model heading. A generic wet-weight footer supplies **no numeric weight**; a horsepower “class” supplies **no exact output**. Neither fills a null.
- A retrieval date describes when a page was checked, not independent confirmation of every statement. Manufacturer power ratings are claims; BRP mountain-turbo ratings retain their altitude qualification. Editorial fit, purchase implications and alternatives are labeled desk-research inferences.

## Editorial implementation

- Reworked every profile's decision analysis, removing public internal-change commentary and claims about previously deleted numbers. Retained useful uncertainty as field-specific evidence notes, not repetitive generic defensiveness.
- Every ID has configuration, two analysis paragraphs, fit, limitations, three seller questions and linked alternatives. Alternatives now distinguish meaningful shock, track, engine, passenger or work-layout differences, including newly resolved Cat evidence.
- Replaced change-log taglines with current buyer-facing descriptions. No new test results, comparative reliability scores, top-speed predictions or owner identities.
- Guides add primary-source examples: historical Yamaha fee normalization ($17,044 versus $16,899 before other charges), regional R-XC track differences, model-specific deep-lug restrictions and Cat fuel/service obligations. Existing invented arithmetic examples remain explicitly hypothetical.
- Added guide references to the ownership-cost planner and dealer-quote worksheet without claiming model-specific economy, oil consumption, tax rules or resale values. Tools/UI, hydration, release packaging and public deployment validation belong to the main implementation, not this data-only audit.
